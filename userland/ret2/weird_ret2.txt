- file stream oriented programming

sfruttiasmo le trutture dei file (stdin stdou, stderr ecc.)
le strutture sono nella libc, le struct dei file che vengono aperti vengono allocate sull'heap (utile se ho of su heap)


file structure:
- flags
- stream buffer
- file descriptor = usato dal kernel per sapere su che file scrivere

i nomi delle struct dei file iniziano con _IO_num_ ecc..


stream byffer = la libc si salva il contenuto da scrivere su un buffer e viene scritto sul file quando viene fatto un flush o chiusi gli stream.

le strutture dei file vewngono salvate in una linked list

testa = ultimo file allocato, quando un file viene aperto viene messo in testa

vtable = contiene i puntatori a funzione (molto interessante)


! nella libc 2.24 e' stato introdotta una funzione che valida le vtable: IO_validate_vtable

viene chiamata tutte le volte prima di chiamare le funz a vtable, controlla che la funzione sia nel range delle vtable, se non lo e' viene chiamata IO_vtable_check


!! prima di libc 2.24 utilizzava u puntatore a funzione per modificare i buffer ma non ci sono controli su questo puntatore e quindi posso modificare la vtable: posso anche controllare i parametri della funzione se faccio of sulla struttura di un file
